**Автоматизированное тестирование веб-сайта [Automation Exercise](https://automationexercise.com/) с использованием Playwright и Page Object Model.**

---

## 1. Выбранный сайт

[Automation Exercise](https://automationexercise.com/) – учебный интернет-магазин, предоставляющий функционал для тестирования:
- регистрация и авторизация,
- работа с корзиной,
- просмотр товаров,
- подписка на новости,
- форма обратной связи и другие.

---

## 2. Инструмент

- **Playwright** 
- Язык: **JavaScript** (Node.js)
- Используемые подходы: **Page Object Model**, фикстуры, параметризация тестов.

---

## 3. Установка зависимостей

Убедитесь, что у вас установлен **Node.js** 


Установите зависимости:
npm install

Установите браузеры для Playwright :
npx playwright install

Запуск всех тестов
Для запуска всех тестов в headless режиме (без открытия браузера) выполните:
npx playwright test

Запуск тестов в headed режиме
Для запуска с открытым браузером 
npx playwright test --headed

Отчёты
Playwright HTML Report:
npx playwright show-report

Allure Report (дополнительно)
для генерации отчёта:
allure serve allure-results

## 4. Краткое описание

components/ – инкапсулируют логику повторяющихся частей интерфейса (хедер, футер, модальные окна).

fixtures/ – содержат фабрики данных (например, генерацию пользователя для регистрации).

helpers/ – утилиты, не привязанные к конкретной странице (работа с рекламой, датами и т.п.).

pages/ – основные Page Object’ы, каждый класс отвечает за свою страницу.

test-data/ – файлы для загрузки и статические тестовые данные.

tests/ – сами тесты, разбитые по функциональности.

reports/ и test-results/ – генерируются автоматически и не хранятся в репозитории.
